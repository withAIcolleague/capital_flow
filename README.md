# 🌊 Global Capital Flow Monitor

애니메이션 기반의 인포그래픽 스타일로 전 세계 자금 흐름을 모니터링하는 웹 애플리케이션입니다.

## ✨ 주요 특징

### 🎨 **시각적 디자인**
- **애니메이션 기반 인포그래픽**: Framer Motion을 활용한 부드러운 애니메이션
- **글래스모피즘 디자인**: 반투명 유리 효과와 백드롭 블러
- **그라데이션 배경**: 동적 그라데이션과 메시 패턴
- **반응형 레이아웃**: 모든 디바이스에서 최적화된 경험
- **다크/라이트 테마**: 사용자 선호에 따른 테마 전환

### 📊 **데이터 시각화**
- **실시간 카운터**: 숫자가 부드럽게 증가하는 애니메이션
- **자금 흐름 애니메이션**: 자산 간 이동을 시각적으로 표현
- **인터랙티브 차트**: 호버 효과와 툴팁이 있는 차트
- **히트맵**: Cross-asset 상대 강도 표시
- **3D 시각화**: 자금 흐름을 3차원으로 표현

### 🤖 **AI/ML 기능**
- **머신러닝 이상 탐지**: LSTM, Isolation Forest, Autoencoder 등 활용
- **실시간 알림 시스템**: 위험 신호 및 이상 징후 탐지
- **블록체인 분석**: 암호화폐 자금 흐름 추적
- **비제도권 자금 추적**: 그림자경제, 조세회피처 모니터링

### 🚀 **기술 스택**
- **Frontend**: Next.js 14, React 18, TypeScript
- **애니메이션**: Framer Motion
- **스타일링**: Tailwind CSS
- **아이콘**: Lucide React
- **차트**: 커스텀 SVG 기반 차트
- **PWA**: Service Worker, Web App Manifest

## 🎯 **페이지 구성**

### 1. **Overview (개요)**
- 자산군별 최신 규모와 증감율
- 주간 순유입/유출 막대차트
- Cross-asset 히트맵 (13주 표준화 점수)

### 2. **비제도권 자금 추적**
- **그림자경제**: GDP의 10-20% 규모 ($15T)
- **조세회피처**: 역외펀드, 신탁 등 ($8.5T)
- **불법금융**: 마약, 무기, 사이버 범죄 ($1.5T)
- **암호화폐**: 비트코인, 이더리움 등 ($2.5T)
- **현물자산**: 금, 현금, 예술품 등 ($18T)

### 3. **암호화폐 자금 흐름**
- 실시간 시가총액 및 가격 추적
- 24시간 거래량 모니터링
- 자금 흐름 방향 분석
- 위험도 분류 및 카테고리별 필터링

### 4. **실시간 알림 시스템**
- 알림 타입: 자금흐름/위험/이상징후/임계값
- 심각도 레벨: Low/Medium/High/Critical
- 실시간 업데이트 및 음성 알림
- 필터링 기능 및 상태 관리

### 5. **ML 이상 탐지**
- **활성 모델**: LSTM, Isolation Forest, Autoencoder 등
- **정확도**: 94.2% (LSTM 시계열 이상 탐지)
- **응답시간**: 평균 12ms
- **탐지 유형**: 통계적, 패턴, 거래량, 속도, 행동적 이상

### 6. **블록체인 분석**
- **지원 네트워크**: Bitcoin, Ethereum, BSC, Polygon
- **실시간 트랜잭션**: 의심스러운 거래 탐지
- **보안 지표**: 51% 공격 위험, 이중 지출 위험 등
- **네트워크 건강도**: 해시레이트, 난이도, 블록 시간

### 7. **3D 시각화**
- 자금 흐름을 3차원 공간에서 표현
- 인터랙티브 회전 및 줌 기능
- 실시간 데이터 포인트 애니메이션
- 범례 및 통계 정보 표시
